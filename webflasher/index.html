Ayuda

Antes de comenzar

  1. Usa Chrome o Edge y un cable USB de datos.
  2. Selecciona el perfil correcto: 433, 868 o 915 MHz.
  3. Completa tu configuración APRS y selecciona la zona horaria y formato de reloj.
  4. Si activas TX, deberás confirmarlo expresamente antes de instalar.

Conexión DFU

  1. Coloca la T-Impulse en modo DFU.
  2. En Windows, el dispositivo DFU debe utilizar WinUSB.
  3. Si usas Zadig, selecciona únicamente el dispositivo con VID 0483 / PID DF11. El nombre puede variar.
  4. No cambies con Zadig el controlador del dispositivo cuando la T-Impulse esté en modo normal.
  5. Cierra Zadig y cualquier programa que pueda estar usando la pulsera.

Instalación

  1. Pulsa Conectar dispositivo y selecciona la T-Impulse.
  2. Revisa los datos y pulsa Instalar firmware.
  3. No desconectes la pulsera hasta que aparezca instalación completada.
Configuración guardada: el navegador recuerda tus datos, zona horaria y formato de reloj para futuras instalaciones. La confirmación de TX no se guarda y debe realizarse nuevamente.
