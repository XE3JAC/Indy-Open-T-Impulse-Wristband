Manual de uso de Indy Open T-Impulse Wristband: operación de pantallas, GPS, APRS, modos de consumo, suspensión y diagnóstico.

T-ImpulseSTM32L073RZGNSSLoRaAPRS

1. Descripción general

Esta guía describe el uso del firmware v0.1.3 o posterior. La pulsera debe tener un firmware que incluya el bloque FirmwareConfigBlock y haber sido configurada desde el Web Flasher con el perfil de radio correcto.

Pantalla

Hora, indicativo, GPS, satélites y estado TX.

GNSS

Posición, fix, coordenadas y sincronización de hora.

APRS

Estado TX, frecuencia, potencia y próximo intento de baliza.

Consumo

Modos Activo y Ahorro con suspensión automática de pantalla y GNSS.

2. Inicio

  1. Conecte la pulsera por USB o despierte el equipo tocando el sensor.
  2. Espere la pantalla de inicio y, para obtener ubicación, salga al exterior.
  3. La pantalla principal muestra la hora local; antes de contar con hora GNSS muestra el tiempo desde el encendido.
Hora: utiliza la zona horaria y el formato de 12/24 horas configurados en el Web Flasher. El cambio de zona horaria solo modifica el reloj visible.

3. Navegación entre pantallas

Un toque breve pasa a la siguiente pantalla. El recorrido es circular:

Principal → GPS → APRS → Principal

El indicador inferior marca la página actual con un punto lleno.

4. Pantalla principal

Muestra la hora, el indicativo APRS, el estado GPS, satélites y TX.

IndicadorSignificado
GOKGPS con posición válida.
G..GPS buscando posición.
S08Ocho satélites detectados.
T+Transmisión habilitada con indicativo válido.
T-Transmisión bloqueada.
B--La lectura de batería todavía no está disponible en este firmware.

5. Pantalla GPS

Muestra satélites, estado de fix y coordenadas. Si aparece FIX NO, las coordenadas no se muestran porque no existe una posición actual válida.

6. Pantalla APRS

Muestra indicativo, frecuencia, potencia, estado TX y el tiempo estimado hasta la próxima baliza.

LASTAntigüedad de la última transmisión realizada desde el arranque.
NEXTTiempo estimado hasta el siguiente intento de baliza.

7. Modos de consumo

Mantenga el sensor entre 0.9 y 1.8 segundos y luego suéltelo para alternar el modo. La pantalla confirma MODO ACTIVO o MODO AHORRO.

ModoPantallaGNSS
ActivoSe apaga a los 10 sPermanece encendido
AhorroSe apaga a los 5 sTras 45 s con pantalla apagada y fix válido, se apaga; vuelve cada 2 min o con un toque
El modo se mantiene mientras la pulsera permanezca encendida. Tras reinicio o salida de suspensión profunda, vuelve al modo Activo.

8. Apagar y despertar

Mantenga el sensor durante 1.8 segundos para entrar en suspensión profunda. La radio, GNSS y pantalla se apagan. Toque el sensor para despertar; la pulsera reinicia el firmware.

El apagado automático de pantalla no apaga el firmware: GPS, LoRa, APRS y los temporizadores continúan funcionando. El primer toque solo despierta la pantalla y conserva la página anterior; el segundo toque pasa a la siguiente pantalla.

9. Transmisión APRS

Para habilitar TX desde el Web Flasher deben configurarse:

  • Un indicativo APRS válido, distinto de NOCALL.
  • txEnabled = 1.
  • Perfil correcto para el módulo y la banda.
  • CRC-32 actualizado en el FirmwareConfigBlock.

Con TX activado, las balizas se emiten automáticamente con posición GNSS válida según SmartBeaconing.

Importante: no hay baliza manual por toque, para evitar transmisiones accidentales mientras se navega por la pantalla.

10. Diagnóstico por USB

Abra el puerto serie a 115200 baudios.

MensajeSignificado
OLED 0x3C: detectadoPantalla I²C encontrada.
DISPLAY WAKE / DISPLAY SLEEPCambio de estado del OLED.
SCREEN HOME, SCREEN GPS, SCREEN APRSCambio de pantalla.
POWER MODE ACTIVO / POWER MODE AHORROCambio de modo.
GPS SLEEP (ahorro) / GPS WAKE (...)Ciclo de GNSS en Ahorro.
TX - OFF: transmision bloqueadaTX no está autorizado por la configuración.

11. Limitaciones actuales

  • La T-Impulse utiliza un solo sensor táctil digital para los controles.
  • No detecta swipe izquierdo/derecho real.
  • No detecta gesto de levantar muñeca porque el proyecto actual no declara un IMU/acelerómetro operativo.
  • Todavía no hay lectura de batería integrada.

12. Web Flasher

La configuración del dispositivo se realiza mediante el Web Flasher de Indy Open T-Impulse Wristband.

Abrir Web Flasher
Desde el Web Flasher se configura el perfil de radio y los parámetros del FirmwareConfigBlock antes de instalar el firmware.
