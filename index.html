Manual de uso de Indy Open T-Impulse Wristband: pantallas, controles, GNSS, APRS, batería, modos de consumo y diagnóstico.

T-Impulse STM32L073RZ GNSS LoRa APRS

1. Descripción general

Esta guía describe el uso del firmware v0.1.4 o posterior. La pulsera debe tener un firmware que incluya el bloque FirmwareConfigBlock y haber sido configurada desde el Web Flasher con el perfil de radio correcto.

Reloj

Hora local e indicativo APRS.

GPS

Estado de fix y número de satélites.

APRS

Estado TX, balizas confirmadas y próxima transmisión.

Batería

Voltaje y porcentaje aproximado.

Modo

Estado ACTIVO o AHORRO.

2. Inicio

  1. Conecte la pulsera por USB o despierte el equipo tocando el sensor.
  2. Espere la pantalla de inicio y, para obtener ubicación, salga al exterior.
  3. La pantalla principal muestra la hora local; antes de contar con hora GNSS muestra el tiempo desde el encendido.
Hora: utiliza la zona horaria y el formato 12/24 horas configurados en el Web Flasher. El cambio de zona horaria solo modifica el reloj visible.

3. Pantallas y controles

Un toque breve pasa a la siguiente pantalla. El recorrido es circular:

Reloj → GPS → APRS → Batería → Modo → Reloj

Controles

GestoAcción
Toque breveCambia a la siguiente pantalla.
Doble toqueAlterna entre modo ACTIVO y AHORRO.
Toque largo de 2 sApaga la pulsera y entra en suspensión profunda.
La interfaz utiliza una etiqueta pequeña, un dato principal grande y un detalle breve para conservar legibilidad en el OLED de 64×32 píxeles.

7. Batería

Muestra el voltaje y el porcentaje aproximado calculado a partir de ADC1 / canal 14. La lectura promedia 20 muestras y se filtra para evitar saltos durante una transmisión LoRa.

BATERIA
3.19V 82%
Calibración: el voltaje y porcentaje son provisionales hasta calibrarlos con mediciones reales de batería cargada y descargada.

9. Modos de consumo

Dé dos toques breves al sensor para alternar el modo. La pantalla temporal solo muestra MODO y ACTIVO o AHORRO.

ModoPantallaGNSS
ActivoSe apaga a los 10 sPermanece encendido
AhorroSe apaga a los 5 sTras 45 s con fix o 60 s sin fix, se apaga; vuelve cada 2 min o con un toque

El modo se mantiene mientras la pulsera permanezca encendida. Tras reinicio o salida de suspensión profunda, vuelve al modo Activo.

10. Apagar y despertar

Mantenga el sensor 2 segundos y luego suéltelo para entrar en suspensión profunda. La radio, GNSS y pantalla se apagan.

Toque el sensor para despertar; la pulsera reinicia el firmware.

El apagado automático de pantalla no apaga el firmware: GPS, LoRa, APRS y los temporizadores continúan funcionando. El primer toque solo despierta la pantalla y conserva la página anterior; el segundo toque pasa a la siguiente pantalla.

11. Transmisión APRS

Para habilitar TX desde el Web Flasher deben configurarse:

  • Un indicativo APRS válido, distinto de NOCALL.
  • txEnabled = 1.
  • Perfil correcto para el módulo y la banda.
  • CRC-32 actualizado en el FirmwareConfigBlock.

Con TX activado, las balizas se emiten automáticamente con posición GNSS válida según SmartBeaconing.

No hay baliza manual por toque, para evitar transmisiones accidentales mientras se navega por la pantalla.

13. Limitaciones actuales

  • La T-Impulse utiliza un solo sensor táctil digital para los controles.
  • No detecta swipe izquierdo/derecho real.
  • No detecta gesto de levantar muñeca porque el proyecto actual no declara un IMU/acelerómetro operativo.
  • La conversión actual de batería a voltaje y porcentaje es provisional y falta calibrarla contra mediciones reales.
